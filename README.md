## ✨ Overview

This repository contains small, interactive web applications that focus on building practical JavaScript skills through hands-on projects.  
Each mini project is designed to improve understanding of:

- DOM manipulation
- Event handling
- Basic state management
- UI design and responsiveness
- Core front-end development concepts

---

## 🚀 Projects

### 1. Counter App
A simple counter application that lets users increment, decrement, and reset a value.

### 2. Quiz Application
An interactive quiz app that presents questions and helps users test their knowledge.

### 3. To-Do List
A task management app for adding, completing, and removing daily tasks.
