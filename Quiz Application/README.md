
# Quiz Application

<p align="center">
  An interactive quiz app built with **HTML**, **CSS**, and **JavaScript**.
</p>

---

## ✨ Overview

The **Quiz Application** presents questions with multiple-choice answers and displays progress as the user moves through the quiz.  
It is designed to strengthen JavaScript logic, user interaction handling, and dynamic UI updates.

---

## 🚀 Features

- Multiple-choice questions
- Progress tracking
- Answer feedback/message display
- Next question navigation
- Simple and engaging interface

---

## 🛠️ Tech Stack

- **HTML** — page structure
- **CSS** — layout and styling
- **JavaScript** — quiz logic and interactivity

---

## ▶️ How to Run

1. Open the `Quiz Application` folder.
2. Open `index.html` in your browser.
3. Start answering the quiz questions.
