
# To-Do List

<p align="center">
  A clean and practical to-do list app built with **HTML**, **CSS**, and **JavaScript**.
</p>

---

## ✨ Overview

The **To-Do List** project allows users to add, track, and manage tasks in a simple interface.  
It is a useful mini project for practicing DOM manipulation, user input handling, and state updates in JavaScript.

---

## 🚀 Features

- Add new tasks
- View total tasks
- Track completed tasks
- Track pending tasks
- Simple and user-friendly layout

---

## 🛠️ Tech Stack

- **HTML** — structure
- **CSS** — styling
- **JavaScript** — task management logic

---

## ▶️ How to Run

1. Open the `To-Do List` folder.
2. Open `index.html` in your browser.
3. Add tasks and manage them using the interface.
