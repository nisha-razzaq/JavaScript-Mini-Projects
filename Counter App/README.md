
# Counter App

<p align="center">
  A simple and interactive counter application built with **HTML**, **CSS**, and **JavaScript**.
</p>

---

## ✨ Overview

The **Counter App** is a beginner-friendly mini project that allows users to increase, decrease, and reset a counter value.  
It is a great project for learning DOM manipulation and event handling in JavaScript.

---

## 🚀 Features

- Increase counter value
- Decrease counter value
- Reset counter to zero
- Clean and minimal UI
- Responsive layout

---

## 🛠️ Tech Stack

- **HTML** — structure
- **CSS** — styling
- **JavaScript** — functionality

---

## ▶️ How to Run

1. Open the `Counter App` folder.
2. Open `index.html` in your browser.
3. Use the buttons to control the counter.
